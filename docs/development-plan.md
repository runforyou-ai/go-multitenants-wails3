# 开发与 PR 计划

本文把脚手架从「仅有规格」推进到「可作为 Template 使用」拆成可独立合并的 PR。每项含目标、范围、验收；依赖未满足前不开始后续 PR。

约束见 [AGENTS.md](../AGENTS.md)；能力见 [capabilities.md](./capabilities.md)、[clients.md](./clients.md)。

自动化测试：**仅 Postgres 集成测试**。

---

## 总览

  → PR4 平台 Cookie 认证 + 安装引导

  → PR7 ops-web 空壳

  → PR9 代登录 + 审计
  → PR10 cache + jobq
  → PR11 邮件（找回密码等）
  → PR12 对象存储 + 分片上传（Uppy）
  → PR13 Docker 部署
  → PR14 Wails 桌面最小路径（JWT + platform 抽象）

- PR7 ∥ PR8（双前端空壳）

## PR0 — 规格入库

**目标：** 本 `docs/` + `AGENTS.md` + 根 `README` 合入 `main`。  

**范围：** 仅文档。  

**验收：** 身份、架构、技术栈、能力、客户端、本计划文档齐全；无实现代码要求。  

**状态：** 进行中（当前工作区已起草，待首次 commit / push）。

---

## PR1 — 仓库骨架与工具链

**目标：** 可编译的空服务 + Task / pnpm 工作区雏形。  

**范围：**

- Go module、`cmd` 入口占位、`wails3 task`（或等价）常用任务  
- `apps/ops-web`、`apps/tenant-web` 空前端包（pnpm workspace）  
- CI：go test（可先无集成用例）、pnpm lock、基础 lint  
- `.env.example`、gitignore  

**不包含：** 业务、真实认证、Wails 完整多平台矩阵（可先占位目录）。  

**验收：** `task`（或文档写明的命令）能起空进程；pnpm install 通过。

---

## PR2 — 配置加载

**目标：** 开发 env 为主、生产 yaml 为主、环境变量覆盖 yaml。  

**范围：** 配置结构体、加载顺序、`.env.example` / 示例 `config.yaml`；监听与 Postgres DSN 等基础设施字段。  

**验收：** 集成或单元级加载测试（若仅有纯函数可用表驱动测试；与库交互的仍归集成测试）；文档与 [architecture.md](./architecture.md) 配置节一致。

---

## PR3 — 租户 / 用户数据模型

**目标：** 迁移与 model：User、Tenant、平台授权、租户成员、角色字段。  

**范围：** 迁移 + model/domain；集成测试覆盖建表与基本约束（邮箱唯一等）。  

**不包含：** HTTP 登录。  

**验收：** 在 `TEST_POSTGRES_*` 下迁移可 Up；集成测试通过。

---

## PR4 — 平台 Cookie 认证与安装

**目标：** 首装创建平台管理员；运营后台可 Cookie 登录 / 登出 / me。  

**范围：** session 表或等效、安装状态、平台登录 API；集成测试。  

**验收：** 冷库启动 → 安装 → Cookie 会话读写 me；未安装态行为明确。

---

## PR5 — 租户 JWT 与开户

**目标：** 租户登录 JWT；代建（租户+用户一次齐）；可选开放注册开租户。  

**范围：** JWT 签发/校验、开户 API、租户上下文；集成测试。  

**验收：** 代建后可用 JWT 调租户 me；注册开关关闭时拒绝自助开户。

---

## PR6 — RBAC

**目标：** 平台角色与租户角色门闸。  

**范围：** 权限中间件 / 校验；若干示例权限点；集成测试（越权 403）。  

**验收：** 无权限无法访问受保护管理 API；有权限可访问。

---

## PR7 — ops-web 空壳

**目标：** Refine + shadcn + TW v4 运营壳：登录、布局、占位首页、接平台 Cookie。  

**范围：** 登录页、壳布局、i18n 骨架、调用平台 me。  

**验收：** 浏览器可登录运营台并看到壳；无 DOM 探测类自动化测试。

---

## PR8 — tenant-web 空壳

**目标：** shadcn sidebar-01 + TanStack/RHF 租户壳：JWT 登录、布局、占位首页。  

**范围：** 与 PR7 对称；共享 tokens 策略可另开小 PR。  

**验收：** 租户用户 JWT 登录后进入租户壳。

---

## PR9 — 代登录与审计

**目标：** 运营代登录进入租户端；审计谁、何时、哪租户、结束时间。  

**范围：** 代登录令牌或临时会话、审计表/写入、ops-web 入口、tenant-web 横幅提示。  

**验收：** 集成测试覆盖代登录签发与过期；审计记录可查。

---

## PR10 — cache 与 jobq

**目标：** 接入 `cache`、`jobq`（Postgres 驱动）；示例缓存键与示例异步/定时任务。  

**范围：** 装配、健康依赖、一个演示任务 + 集成测试。  

**验收：** 任务可入队执行；进程重启后 jobq/PG 状态仍一致（按库语义）。

---

## PR11 — 邮件

**目标：** 部署级邮件配置；找回密码（及可选通知）。  

**范围：** 发信抽象、重置流程、集成测试可用假 mailer。  

**验收：** 请求重置产生令牌；用令牌改密后旧会话/JWT 策略符合规格。

---

## PR12 — 对象存储与分片上传

**目标：** 部署级 OSS；服务端上传协议；tenant-web（及需要时 ops）Uppy 分片上传。  

**范围：** 直传/分片会话 API、Uppy 对接；集成测试可用 minio 或 mock（若 CI 仅 PG，可对协议层测 + 文档要求本地 minio）。  

**验收：** 完成一次分片上传并得到可访问对象（或等价断言）。

---

## PR13 — Docker 部署

**目标：** Compose：Postgres + 应用；生产向 yaml 示例。  

**范围：** Dockerfile、compose、文档中的启动步骤。  

**验收：** 按文档可一键起栈并完成安装与双端登录（手工验收即可）。

---

## PR14 — Wails 桌面最小路径

**目标：** 桌面壳可构建；连接服务器；租户 JWT 登录；`platform` 抽象（web/native）。  

**范围：** 见 [clients.md](./clients.md) 中连接服、外链、窗体模式等最小集；托盘/更新可后续 PR。  

**验收：** 桌面构建成功；连本地服务登录租户壳；集成测试仍只测服务端。

---

## PR15 — 移动端路径与阿里云推送

**目标：** 移动标准工程可构建；设备登记到登录会话；服务端经阿里云推送投递（可对推送客户端做接口假实现测登记与任务）。  

**范围：** [clients.md](./clients.md) 推送节；部署配置项。  

**验收：** `SetPushDevice` 类行为集成测试通过；推送发送路径可注入 fake relay。

---

## PR16 — 客户端更新、签名与分发

**目标：** 更新清单、签名校验、服务端下载页；桌面「准备更新 / 重启」最小闭环（平台差异按 clients 文档）。  

**验收：** 清单与校验逻辑有集成或可测纯函数 + 文档化手工步骤；假清单可驱动状态机。

---

## PR17 — 开源 / 商业 edition

**目标：** 构建门闸与目录/标签约定；商业模块示例（可为空壳 feature flag）。  

**验收：** 开源默认构建不含商业符号；商业构建可打开示例门闸。

---

## PR18 — 模板打磨

**目标：** Template 可用性：替换模块路径说明、品牌占位、最小「示例业务」页（证明扩展方式）、导出/检查清单。  

**验收：** 按 README 从模板新建仓库的步骤可走通（手工）。

---

## PR 合并约定

1. 单 PR 单一主题；描述写清目标与验收。  
2. 先合并依赖方；禁止把未就绪的大前端与内核揉进同一巨型 PR。  
3. 破坏性迁移须在 PR 说明中写明。  
4. 不在 PR 中加入页面元素探测类测试。  
5. 合入 `main` 的迁移文件不再改写历史。
