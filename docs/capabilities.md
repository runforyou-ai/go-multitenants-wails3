# 基础能力清单

下列为脚手架**应具备**的能力。标注「槽位」表示提供模型与接口位置，具体策略由产品收窄或扩展。实现可分批交付，但规格上视为底座范围。

## 1. 身份与租户

| 能力 | 说明 |
|------|------|
| 初始化 / 安装引导 | 首次部署写入必要状态与首个平台管理员等 |
| 平台登录 / 登出 | Cookie 会话 |
| 租户登录 / 登出 | JWT；Web 与客户端共用 |
| 注册开租户 | 可关闭；注册 = 租户 + 首管理员 |
| 运营代建 | 一次创建租户 + 用户（无邀请主路径） |
| 平台 RBAC | 平台角色与权限门闸 |
| 租户 RBAC | 租户内角色与权限门闸 |
| 多租户隔离 | 数据与配置按租户隔离 |
| 运营代登录租户端 | 可审计、有时效 |
| 租户 API 凭证槽位 | 与登录分离；查看/重置可二次验证 |
| 用户禁用 / 租户停用 | 治理用 |
| 密码找回 | 依赖部署级邮件配置 |

## 2. 平台与任务

| 能力 | 说明 |
|------|------|
| 缓存 | [`cache`](https://github.com/runforyou-ai/cache)，Postgres 驱动 |
| 异步任务 | [`jobq`](https://github.com/runforyou-ai/jobq)，Postgres 驱动 |
| 定时任务 | [`jobq`](https://github.com/runforyou-ai/jobq)，Postgres 驱动 |
| 审计日志 | 至少覆盖：登录失败策略相关、代登录、角色变更、凭证重置 |
| 健康检查 | 存活 / 就绪，便于 Docker |

## 3. 文件

| 能力 | 说明 |
|------|------|
| 对象存储 | 部署级配置（S3 兼容等） |
| 分片上传 | 服务端协议 + 租户端 Uppy |
| 直传 / 上传会话 | 按 luway-cloud 一类实践提供安全上传凭证流 |

## 4. 前端工作台

| 能力 | 说明 |
|------|------|
| ops-web 壳 | 布局、鉴权门闸、i18n、基础 CRUD 范式（Refine） |
| tenant-web 壳 | sidebar-01 起点、鉴权、租户上下文、i18n |
| 主题 / 品牌可替换 | 框架固定，风格可换 |

## 5. 客户端与发行

| 能力 | 说明 |
|------|------|
| Wails3 桌面 / 移动工程 | 始终保留，可构建 |
| 连接自建服务器 / 换服 | 地址检测、保存、回填 |
| 系统通知与点击回跳 | 权限、投递、打开应用内路径 |
| 阿里云移动推送 | 设备登记到登录会话；离线投递；部署级密钥配置 |
| 未读角标 / 托盘提醒 | 桌面托盘与图标；移动角标 |
| 深链唤起 | 自定义协议打开应用并可带部署地址 |
| 客户端版本检查与更新 | 清单、签名校验；自替换或引导下载页 |
| 原生选图 / 另存为 | 系统文件对话框 |
| 桌面壳 | 入口窗/工作台窗、托盘、菜单、关窗驻留等（见 [clients.md](./clients.md)） |
| 签名与发布任务 | 商业与开源通道可分 |
| 开源 / 商业双轨 | edition / 构建门闸 |
| Docker 服务端部署 | Compose 或等效 |
| 发版可选不附带客户端 | 构建能力仍在 |

完整桌面 / 移动能力表见 [clients.md](./clients.md)。

## 6. 建议具备的安全与运营基线

| 能力 | 说明 |
|------|------|
| 会话 / JWT 吊销或失效策略 | 改密、禁用后失效 |
| 二次验证槽位 | 敏感操作（重置密钥、代登录确认等） |
| 2FA 槽位 | 可先空实现，模型预留 |
| Webhook 出站槽位 | 可先空实现 |
| 基础 metrics / 结构化日志 | slog；指标按需 |
