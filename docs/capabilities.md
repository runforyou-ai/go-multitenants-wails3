# 基础能力清单

脚手架**应具备**的能力。实现分批见 [development-plan.md](./development-plan.md)。

## 1. 身份与租户

| 能力 | 说明 |
|------|------|
| 初始化 / 安装引导 | 首次部署与首个平台管理员等 |
| 平台登录 / 登出 | Cookie 会话 |
| 租户登录 / 登出 | JWT + refresh（或等效）；滑动窗口续期；Web 与客户端共用 |
| 注册开租户 | 可关闭；注册 = 租户 + 首管理员 |
| 运营代建 | 一次创建租户 + 用户 |
| 平台 RBAC | 平台角色与权限门闸 |
| 租户 RBAC | 租户内角色与权限门闸 |
| 多租户隔离 | 数据与配置按租户隔离 |
| 运营代登录租户端 | 可审计、有时效；临时令牌 |
| 租户 API 凭证 | 与登录分离；查看/重置二次验证 |
| 用户禁用 / 租户停用 | 治理用；既有登录态失效 |
| 密码找回 | 依赖部署级邮件配置 |

## 2. 平台与任务

| 能力 | 说明 |
|------|------|
| 缓存 | [`cache`](https://github.com/runforyou-ai/cache)，Postgres 驱动 |
| 异步 / 定时任务 | [`jobq`](https://github.com/runforyou-ai/jobq)，Postgres 驱动 |
| 审计日志 | 至少：登录失败相关、代登录、角色变更、凭证重置 |
| 健康检查 | 存活 / 就绪 |

## 3. 文件

| 能力 | 说明 |
|------|------|
| 对象存储 | 部署级配置（S3 兼容等） |
| 分片上传 | 服务端协议 + 租户端 Uppy |
| 直传 / 上传会话 | 安全上传凭证流 |

## 4. 前端工作台

| 能力 | 说明 |
|------|------|
| ops-web 壳 | 布局、鉴权、i18n、Refine CRUD 范式 |
| tenant-web 壳 | sidebar-01、鉴权、租户上下文、i18n；同一 Vite 供 Wails 加载 |
| 主题 / 品牌可替换 | 框架固定，风格可换 |
| 富文本 demo | TipTap 示范页；无流式渲染要求 |

## 5. 客户端与发行

| 能力 | 说明 |
|------|------|
| Wails3 桌面 / 移动 | 始终可构建；打包写入默认服务器 |
| 开源换服 | 开源客户端可展示并更换服务器；非开源写死默认服 |
| 客户端一期能力 | 见 [clients.md](./clients.md)（通知、托盘、更新等） |
| 移动推送 | **仅商业版**；开源不含 |
| 开源 / 商业双轨 | edition 门闸；开源无推送、可换服 |
| Docker 服务端 | Compose 或等效 |
| 发版可选不附带客户端 | 构建能力仍在 |

客户端二期（菜单打磨、多窗口等）见 clients.md，不阻塞 Template。

## 6. 安全与运营基线

| 能力 | 说明 |
|------|------|
| 会话 / JWT 失效 | 改密、禁用、停用后失效；租户 JWT 滑动续期 |
| 二次验证 | 敏感操作（重置密钥、代登录确认等） |
| 2FA | 完整双因素（绑定、登录校验、关闭等） |
| Webhook 出站 | 完整出站 Webhook（配置与投递等） |
| 结构化日志 | slog；指标按需 |
