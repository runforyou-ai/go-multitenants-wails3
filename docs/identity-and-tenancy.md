# 身份与租户规格

本文描述脚手架的身份、租户与登录形态。实现细节（表名、JWT 库等）以代码为准，但不得违背本文语义。

---

## 1. 目标与非目标

**目标**

- 标准多租户：平台运营后台 + 租户控制台（+ 可选客户端，同一租户登录体系）。  
- 一套用户账号；经营与隔离单元是**租户**。  
- 平台 Cookie、租户 JWT；对外业务调用使用租户 API 凭证（与登录分离）。  
- 开户：内部代建、开放注册；邀请不是主路径。  
- 支持运营人员**代登录**到租户端（带审计与时效）。  

**非目标**

- 单租户全局 `admin` / `user` 工具后台。  
- 两套互不相通的用户系统（运营一套人、租户一套人物理拆号）——用授权/成员关系区分身份。  
- 规定具体业务域（模型、IM、商品等）。  

---

## 2. 核心实体

| 实体 | 含义 |
|------|------|
| **租户（Tenant）** | 经营与隔离单元。业务配置、成员、租户 API 凭证挂在租户上。 |
| **用户（User）** | 可登录的人。登录邮箱**全局唯一**。一张用户表。 |
| **平台授权** | 用户是否具备平台侧身份及平台角色。平台运营**不属于**业务租户。 |
| **租户成员** | 用户 ↔ 租户 及租户内角色。同一用户可属于多个租户。 |

```text
User ──┬──（可选）平台授权 ──────────► 运营后台（Cookie）
       └──（可选）租户成员 × N ──────► 租户控制台 / 客户端（JWT）

Tenant ── 配置 / 成员 / 租户 API 凭证
```

- **平台用户** = 拥有平台授权的人。  
- **租户用户** = 拥有至少一条租户成员关系的人。  
- 同一人可以同时具备两者（结构允许）。是否互斥由**策略校验**控制。  

---

## 3. 工作台与凭证

| 空间 | 谁 | 凭证 | 能力边界 |
|------|----|------|----------|
| **运营后台** | 平台授权用户 | **Cookie** | 开户、治租户、平台设置、代登录等；**默认无租户业务调用权** |
| **租户控制台 / 客户端** | 租户成员 | **JWT**（Bearer）+ **refresh（或等效）** | 仅本租户；claim 须能确定 `user` + `tenant` |
| **对外业务 API** | 服务 / 集成 | **租户 API 凭证** | 产品启用；**不能**用平台 Cookie 或用户 JWT 代替 |

三层不得混用。

### 租户登录续期（滑动窗口）

租户 JWT 须支持 refresh（或等效），并呈**滑动过期**：窗口内有活动则重新起算完整窗口（例如窗口 24h，第 23h 有活动则再保有约 24h，而不是再过 1h 就掉线）。改密、禁用用户、停用租户后，access / refresh 均须失效。

### 代登录（Impersonation）

- 运营在授权下可「进入」某租户的租户端视角。  
- 必须可审计（谁、何时、哪个租户、何时结束）。  
- 须有时效；结束代登录后恢复平台身份。  
- 不意味着永久成为该租户成员；用**临时令牌**（或等效临时会话）实现，不写入正式成员关系。  

---

## 4. 角色与权限

平台与租户**两套角色命名空间**。

**平台侧（可裁剪）**

- 平台管理员  
- 可扩展：运营、只读客服等  

**租户侧（可裁剪）**

- 租户管理员  
- 可扩展：成员、开发者等  

原则：

- 权限挂在平台授权 / 租户成员上，而不是用户表上单一全局 `role`。  
- 两边都要做权限管理；早期产品可将租户侧先做成「皆为管理员」，但模型保留角色字段。  

---

## 5. 开户路径

| 路径 | 行为 |
|------|------|
| **内部代建** | 一次创建：租户 + 至少一名租户用户（及成员关系）。**不依赖邀请链接。** |
| **开放注册**（可关） | 创建租户 + 首个租户管理员。默认配额与能力由产品定少。 |
| **平台运营账号** | 创建用户并授予平台授权。由平台管理员预建；**平台无自助注册。** |

租户内再添加成员：控制台直接创建或绑定已有用户；邀请邮件为可选增强。

---

## 6. 租户 API 凭证

- 脚手架提供租户级对外调用凭证（与登录分离），须可管理与校验。  
- 形态（一租户一密 / 多密钥）由产品选择。  
- 查看 / 重置走二次验证。  
- 额度、告警、限流等挂租户（或挂凭证，语义仍属租户）。  

平台用户不持有此类凭证。

---

## 7. 原则清单

1. 租户是经营与隔离单元；平台运营不算租户。  
2. 一套用户表；平台身份与租户身份用授权 / 成员表达。  
3. 平台登录 Cookie；租户登录 JWT + 滑动续期（Web 与客户端同一体系）。  
4. 对外业务调用用租户 API 凭证，与登录分离。  
5. 代建一次齐；注册开租户；邀请非主路径。  
6. 支持运营代登录租户端，且可审计、有时效。  
7. 两边均可 RBAC；角色命名空间分离。  
8. 同人跨两边结构允许，互斥为策略。  
9. 业务配置留给产品，不进底座必选业务域。
