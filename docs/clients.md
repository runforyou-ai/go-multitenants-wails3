# 桌面端与移动端能力

将**常用、与具体业务弱耦合**的能力纳入脚手架。业务专属能力由产品扩展；脚手架提供原生能力边界与 `web | desktop | mobile` 抽象。

原则：

- 前端经统一 `platform` 层调用本机能力；Web 与原生各有实现。  
- **原生层不承载业务 API、不持久化账号令牌**；令牌与业务请求仍走服务端 HTTP。  
- 仓库保留完整客户端工程与构建；发版可不附带安装包。  
- **服务器地址按 edition：** 打包时写入默认 API 根地址。非开源客户端默认**写死**该地址、不提供换服。**开源版**客户端展示当前服务器并支持更换（实现细节落地时定）。Web 仍用当前 origin。  
- **移动推送仅商业版**；开源构建不含推送。  

交付分两期：一期随 [development-plan.md](./development-plan.md) 客户端里程碑；二期为通用增强。

---

## 1. 一期（脚手架必达）

### 三端共性

| 能力 | 说明 |
|------|------|
| 平台识别 | `web` / `desktop` / `mobile` |
| 默认服务器 | 打包写入默认 API 根地址 |
| 开源换服 | **仅开源 edition**：展示服务器地址并可更换；非开源不提供 |
| 打开外部链接 | 系统浏览器打开 URL |
| 通知权限 | 查询 / 申请；必要时引导系统设置 |
| 本地通知 | 标题、正文、点击后打开的应用内路径 |
| 通知点击回跳 | 聚焦应用并打开约定路径 |
| 未读提示 | 图标角标 / 托盘强调（无未读时清空） |
| 深链唤起 | 自定义协议打开应用并可带应用内路径 |
| 版本匹配与更新 | 检查兼容；清单 + 签名；能自替换则下载重启，否则引导下载页 |
| 原生选图 / 另存为 | 系统文件对话框 |
| 服务端分发页 | 各平台安装包与清单下载 |

### 桌面

| 能力 | 说明 |
|------|------|
| 入口窗 / 工作台窗 | 登录用小窗；进入工作台后主窗可缩放并居中 |
| 窗口控件与拖动 | 各平台标题栏惯例；顶栏拖动 |
| 关闭与托盘 | 关主窗可进托盘；菜单退出结束进程；托盘与未读联动 |
| 后台运行 | 关窗后进程仍在，便于通知与再打开 |

### 移动

| 能力 | 说明 |
|------|------|
| 登录流 | 默认服务器（开源可换服）+ 租户 JWT |
| 系统通知 | 权限、本地通知、点击打开路径 |
| 未读角标 | 按平台提供 |
| 深链 / 更新 / 选图 | 与上表共性一致；移动更新多引导下载页 |

移动端不提供托盘、多窗口、窗内应用菜单等桌面专属交互。

### 移动推送（仅商业版）

商业 edition：离线/后台推送（默认阿里云，部署级配置）；设备登记挂当前登录会话。  
开源构建：**不包含**推送相关代码与配置项。

## 2. 二期（通用增强，不阻塞 Template）

| 能力 | 说明 |
|------|------|
| 界面语言同步到原生 | 菜单、托盘、原生错误文案随界面语言 |
| 应用菜单与缩放全屏 | Windows / Linux 窗内菜单；页面缩放、全屏 |
| 多窗口范式 | 辅助窗、登录态变化关窗、同 ID 聚焦 |
| 通知细节 | 声音开关等 |
| 更新边缘路径 | 如 Linux / 无写权限时的引导体验打磨 |

---

## 3. 与 Web 的边界

| | Web | 桌面 / 移动 |
|--|-----|-------------|
| 服务器 | 当前 origin | 打包写入的默认地址；**开源版**可更换 |
| 通知 | 浏览器 Notification | 系统通知；商业移动另有推送 |
| 未读角标 / 托盘 | 通常无 | 有 |
| 自动更新 | 随站点发布 | 清单 + 签名 |
| 文件 | 浏览器上传/下载 | 可叠加原生对话框 |

同一套租户 JWT（含刷新）与业务 API；差异在 `platform` 实现。

## 4. 发布与构建

- 多平台 Task；`ARCH` 等；Wails 与前端 runtime、CLI 版本锁定。  
- 打包注入默认 API 根地址。  
- 开源 / 商业与服务端 edition 对齐：**开源不含推送**；**开源客户端含换服**，非开源客户端写死默认服。  
- 一期按 development-plan 交付；二期可另开 PR。
