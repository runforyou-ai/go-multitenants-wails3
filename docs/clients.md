# 桌面端与移动端能力

参考 luway-cloud 等 Wails3 多端实践，将**常用、与具体业务弱耦合**的能力纳入脚手架。业务专属能力（如 IM 会话独立窗的业务语义）由产品扩展；脚手架提供原生能力边界与 `web | desktop | mobile` 抽象。

原则（与实现一致）：

- 前端经统一 `platform` 层调用本机能力；Web 与原生各有实现。  
- **原生层不承载业务 API、不持久化账号令牌**；令牌与业务请求仍走服务端 HTTP。  
- 仓库保留完整客户端工程与构建；发版可不附带安装包。  

---

## 1. 三端共性

| 能力 | 说明 |
|------|------|
| 平台识别 | 运行时区分 `web` / `desktop` / `mobile`，按平台选择实现 |
| 连接自建服务器 | 输入完整 `https://` / `http://` 地址；检测可用性；保存并回填最近服务器 |
| 更换服务器 | 登录前后可切换部署地址 |
| 打开外部链接 | 系统浏览器打开 URL |
| 界面语言同步 | 将账号/界面语言同步到原生菜单、托盘与原生错误文案（Web 可为空操作） |
| 通知权限 | 查询 / 申请系统或浏览器通知权限；必要时引导系统设置页 |
| 本地通知 | 前台/本机投递（标题、正文、声音开关、点击后打开的应用内路径） |
| 通知点击回跳 | 点击通知后聚焦应用并打开约定路径 |
| 离线推送（移动） | 见下文「阿里云移动推送」 |
| 未读提示 | 同步未读数到图标角标 / 托盘强调（无未读时清空） |
| 深链 / 自定义协议唤起 | 系统链接打开应用；可携带部署地址等参数，由前端消费 |
| 客户端与服务器版本匹配 | 连接时检查兼容；过旧服务器 / 需升级客户端时给出明确页与操作 |
| 从当前服务器更新客户端 | 拉取清单与安装包、校验签名；能自替换则「下载 → 重启更新」，否则引导下载页手动安装 |
| 原生选图 / 保存文件 | 系统文件对话框选图；另存为写入本地文件 |
| 服务端分发页 | 服务端提供各平台安装包与清单下载（与发布流程配套） |

## 2. 桌面端（常用）

| 能力 | 说明 |
|------|------|
| 入口窗 / 工作台窗 | 连接与登录用固定尺寸小窗；进入工作台后切换为可缩放主窗并居中 |
| 窗口控件 | macOS 系统红绿灯；Windows / Linux 自定义标题栏与最小化/最大化/关闭 |
| 拖动区域 | 顶栏空白区域拖动窗口 |
| 应用菜单 | Windows / Linux 窗内菜单（文件/编辑/显示/窗口等）；macOS 系统菜单栏 |
| 缩放与全屏 | 页面缩放、全屏切换 |
| 关闭与退出 | 关主窗可隐藏到托盘；菜单「退出」结束进程 |
| 系统托盘 | 托盘图标、菜单；与未读 / 提醒状态联动 |
| 后台运行 | 关窗后进程仍在，便于通知与再次打开 |
| 自动更新（桌面） | Windows / macOS 优先应用内下载并签名校验后重启更新；Linux 或无写权限时引导下载页 |
| 多窗口（可选范式） | 主窗之外的辅助窗口（如详情/会话）；登录态变化时关闭辅助窗；同 ID 聚焦已有窗 |

导航类（侧栏开关、后退/前进）属于壳层体验体验，与业务路由配合，脚手架提供桌面壳惯例即可。

## 3. 移动端（常用）

| 能力 | 说明 |
|------|------|
| 连接与登录流 | 与桌面相同的服务器检测 / 保存 / 更换 |
| 系统通知 | 权限申请、本地通知、点击打开路径 |
| **阿里云移动推送** | 离线/后台投递；见下节 |
| 未读角标 | 启动器角标类能力按平台提供 |
| 深链唤起 | 与桌面同一套 server-link / 路径约定 |
| 客户端更新 | 通常引导至下载页安装新包；能支持应用内更新的平台按同一清单协议扩展 |
| 原生选图 | 调用系统相册/相机选择能力（经统一选图接口） |
| 安全与后台 | 按平台惯例处理后台与通知；令牌仍不落在原生业务层 |

移动端一般不提供托盘、多窗口工作台、窗内应用菜单等桌面专属交互。

### 阿里云移动推送

脚手架将 **阿里云移动推送** 作为移动端离线通知的标准能力（iOS / Android）：

| 项 | 说明 |
|----|------|
| 设备登记 | 客户端登录后把推送目标记到**当前登录会话**（应用标识、平台、推送服务下发的 deviceId） |
| 会话绑定 | 同一设备换账号/换会话后，只保留最近一次登记；会话过期则不再作为推送目标 |
| 服务端投递 | 业务通知经任务异步发出；按未过期会话上的设备分组调用阿里云推送 |
| 点击行为 | 与本地通知一致：打开约定应用内路径 |
| 配置 | AccessKey、AppKey 等为**部署级配置**（与对象存储、邮件同类），按应用/平台区分 |

前台仍可用本机/系统通知；进程不在前台时走阿里云通道。桌面端不依赖阿里云推送。

## 4. 与 Web 的边界

| | Web | 桌面 / 移动 |
|--|-----|-------------|
| 服务器地址 | 当前页面 origin | 用户配置并持久化 |
| 通知 | 浏览器 Notification（安全上下文） | 系统通知 API |
| 未读角标 / 托盘 | 通常无 | 有 |
| 自动更新 | 随站点发布 | 客户端清单 + 签名 |
| 文件 | 浏览器上传/下载 | 可叠加原生对话框 |

同一套租户 JWT 与业务 API；差异只在 `platform` 实现。

---

## 5. 发布与构建（脚手架范围）

- 多平台 Task（darwin / windows / linux，以及 iOS / Android 标准写法）。  
- 架构参数（如 `ARCH`）。  
- Wails Go 依赖、前端 runtime、CLI **版本锁定一致**。  
- 安装包签名与更新清单校验。  
- 开源 / 商业客户端变体与服务端 edition 对齐。  

细节任务名以本仓 Taskfile 落地为准。

## 6. 产品扩展示例（非脚手架必选业务）

下列在 luway 中存在，但属于协作/IM 域，脚手架只保留「多窗口 / 通知路径」等原语即可：

- 按会话打开业务独立窗的产品交互  
- 渠道消息、客服坐席等业务通知文案与路由  

产品在原语之上组装，不把业务 API 下沉到 `native`。
