# 架构与模块

## 1. 目标

提供可复用的多租户 SaaS 底座：

- Go 后端 + Postgres  
- 运营 Web + 租户 Web（框架固定，风格可换）  
- Wails3 桌面 / 移动标准写法与签名发布能力  
- 开源版与商业版同仓兼容  
- Docker 部署服务端  

产品在租户（及平台）上扩展业务，不另起用户体系。

## 3. 外部依赖

| 依赖 | 说明 |
|------|------|
| **Postgres** | 外部组件仅此一项。主库；[`cache`](https://github.com/runforyou-ai/cache)、[`jobq`](https://github.com/runforyou-ai/jobq) 使用 **Postgres 驱动** |
| 对象存储 | 部署配置（yaml / 环境）：endpoint、桶、密钥等 |
| 邮件（如 Resend） | 部署配置：找回密码、通知等 |
| 阿里云移动推送 | 部署配置：移动端离线推送（AppKey / 密钥等，按应用与平台） |

## 4. 双前端工作台

| 应用 | 受众 | 框架策略 |
|------|------|----------|
| **ops-web** | 平台运营 | 技术栈冻结（见 tech-stack）；换 Logo / 主题 / 业务菜单 |
| **tenant-web** | 租户成员；亦可被 Wails 壳加载 | 另一套冻结栈；换风格与业务页 |

二者为**两个前端应用**，共享约定与可抽取的 tokens/组件，不合并成单一 Refine 应用。

## 5. 客户端策略

- 仓库内**始终保留**完整 Wails3 桌面 / 移动工程与构建、签名、发布文档/任务。  
- 任意基于本模板的产品均可**构建**客户端。  
- **发版**时可选择不发布客户端安装包（例如纯服务端产品）。  
- 客户端登录与租户 Web 一致：消费**租户 JWT**；原生层不持久化令牌、不承载业务 API。  

桌面 / 移动常用能力清单见 [clients.md](./clients.md)。

## 6. 开源版与商业版

参考 luway-cloud 一类同仓双轨：

- 用构建标签、`edition` 或目录隔离商业能力。  
- 开源产物默认不包含商业模块。  
- 身份与租户模型在开源/商业间一致；差异在功能门闸与发行通道。

具体目录与 tag 命名在实现阶段定，但不得破坏「一套租户模型」。

## 7. 配置边界（产品层）

| 类别 | 放哪里 | 示例 |
|------|--------|------|
| 基础设施 | 部署配置（yaml / 环境变量） | 监听、Postgres、对象存储、邮件、日志目录 |
| 平台可运营项 | 平台设置（库内） | 是否开放注册、站点名等 |
| 租户可配置项 | 租户配置 | 成员、业务开关、租户 API 凭证、告警等 |

对象存储与数据库连接属于部署配置；租户配置域承载业务项，不承载基础设施连接串。

**加载约定：** 开发阶段以环境变量为主；生产以 yaml 为主，环境变量可覆盖 yaml 同名项。

## 8. 与业务产品的关系

脚手架提供内核 + 双壳 + 平台能力 + 客户端能力。

业务产品：

- 增加租户（及平台）业务资源与页面  
- 决定发版是否附带客户端  
- 决定启用哪些商业模块  

不在产品中复制第二套登录 / 租户体系。
