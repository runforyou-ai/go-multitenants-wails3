# 架构与模块

## 1. 目标

提供可复用的多租户 SaaS 底座：

- Go 后端 + Postgres  
- 运营 Web + 租户 Web（框架固定，风格可换）  
- Wails3 桌面 / 移动标准写法与签名发布能力  
- 开源版与商业版同仓兼容  
- Docker 部署服务端  

产品在租户（及平台）上扩展业务，不另起用户体系。

## 3. 外部依赖

| 依赖 | 说明 |
|------|------|
| **Postgres** | 外部组件仅此一项。主库；[`cache`](https://github.com/runforyou-ai/cache)、[`jobq`](https://github.com/runforyou-ai/jobq) 使用 **Postgres 驱动** |
| 对象存储 | 部署配置（yaml / 环境）：endpoint、桶、密钥等。运行时硬依赖仍只有 Postgres；本地/CI 可用 MinIO 等辅助 |
| 邮件（如 Resend） | 部署配置：找回密码、通知等 |
| 移动推送 | **仅商业版**；默认阿里云（部署配置）。开源构建不包含 |

## 4. 双前端工作台

| 应用 | 受众 | 框架策略 |
|------|------|----------|
| **ops-web** | 平台运营 | 技术栈冻结（见 tech-stack）；换 Logo / 主题 / 业务菜单 |
| **tenant-web** | 租户成员；**同一 Vite 应用**也被 Wails 壳加载 | 另一套冻结栈；换风格与业务页 |

ops-web 与 tenant-web 为**两个前端应用**，不合并成单一 Refine 应用。tenant-web 与客户端壳之间是「一个 Vite、多种运行环境」，不是两套租户页面工程。

## 5. 客户端策略

- 仓库内**始终保留**完整 Wails3 桌面 / 移动工程与构建、签名、发布文档/任务。  
- 任意基于本模板的产品均可**构建**客户端。  
- **发版**时可选择不发布客户端安装包（例如纯服务端产品）。  
- 客户端登录与租户 Web 一致：租户 JWT + 滑动续期；原生层不持久化令牌、不承载业务 API。  
- 打包写入默认 API 地址；**非开源写死默认服**，**开源版可换服**（见 [clients.md](./clients.md)）。  
- 能力分期与清单见 [clients.md](./clients.md)。  

## 6. 开源版与商业版

同仓双轨：

- 用构建标签、`edition` 或目录隔离商业能力。  
- 开源产物默认不包含商业模块；**开源构建不含移动推送**；**开源客户端支持换服**，非开源客户端打包写死默认服。  
- 身份与租户模型在开源/商业间一致；差异在功能门闸与发行通道。

目录与 tag 命名实现时定；骨架阶段即可留下隔离位置。不得破坏「一套租户模型」。

文中若对照已有产品，只表示原则对齐，**不要求**目录、表名、API 一一对应。

## 7. 配置边界（产品层）

| 类别 | 放哪里 | 示例 |
|------|--------|------|
| 基础设施 | 部署配置（yaml / 环境变量） | 监听、Postgres、对象存储、邮件、日志目录；商业版推送密钥等 |
| 平台可运营项 | 平台设置（库内） | 是否开放注册、站点名等 |
| 租户可配置项 | 租户配置 | 成员、业务开关、租户 API 凭证、告警等 |

对象存储与数据库连接属于部署配置；租户配置域承载业务项，不承载基础设施连接串。

**加载约定：** 开发阶段以环境变量为主；生产以 yaml 为主，环境变量可覆盖 yaml 同名项。

## 8. 与业务产品的关系

脚手架提供内核 + 双壳 + 平台能力 + 客户端能力。

业务产品：

- 增加租户（及平台）业务资源与页面  
- 决定发版是否附带客户端  
- 决定启用哪些商业模块  

不在产品中复制第二套登录 / 租户体系。
